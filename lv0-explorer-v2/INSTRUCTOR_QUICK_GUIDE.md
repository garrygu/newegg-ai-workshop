# 👨‍🏫 Explorer Level V3 - Quick Instructor Guide

## 🎯 Workshop at a Glance

**Total Duration:** 3 classes (~7 hours total)  
**Target Audience:** Kids with no coding experience  
**Final Deliverable:** 1-2 minute AI-generated multimedia story  
**Philosophy:** Project-based learning - students plan THEIR story first, then learn tools to build it!

---

## 📅 Class Schedule

### Class 1: Discover AI Around You (2 hours)
**Already Complete** ✅
- Students learned AI fundamentals
- Explored ChatGPT
- Discussed ethics and "AI for Good"

### Class 2: Plan Your Story & Create with AI (2.5-3 hours)
**What Students Do:**
- Plan their complete story (beginning, middle, end)
- Create detailed storyboard (3-5 scenes)
- Learn AI image generation tools
- Create 3-5 AI images for THEIR story scenes
- Save and organize all images

### Class 3: Animate, Voice & Assemble Your Story (2.5-3 hours)
**What Students Do:**
- Learn AI video animation (Runway ML)
- Create 2-3 animated video clips
- Learn AI voice generation (ElevenLabs)
- Generate voice narration for each scene
- Assemble everything in Canva
- Present their final story!

## 🎓 Teaching Tips

### Class 2 Tips:

**Time Management:**
- **00:00-00:10** - Welcome & review Class 1 (10 min)
- **00:10-00:40** - Story planning & storyboarding (30 min)
- **00:40-01:10** - Learn AI image creation tools (30 min)
- **01:10-01:25** - BREAK (15 min)
- **01:25-02:25** - Create images for YOUR story (60 min)
- **02:25-02:40** - Preview Class 3 & save everything (15 min)

**Common Challenges:**
1. **Story Planning Paralysis**
   - Solution: Have preset story themes students can choose from
   - Use ChatGPT to help brainstorm
   
2. **Storyboard Complexity**
   - Solution: Remind students 3 scenes minimum is totally fine!
   - Simpler stories = easier to complete
   
3. **Prompt Writing Difficulty**
   - Solution: Teach the "prompt recipe" clearly
   - Have prompt templates for each scene type
   
4. **Image Generation Delays**
   - Solution: Students work on next scene's prompt while waiting
   - **PERFECT TIME for music bonus!** ⭐
   - Have them write all prompts before generating

**Pro Tips:**
- ✅ Planning FIRST makes students more motivated to learn tools!
- ✅ Show connection: "This image will become YOUR scene 1"
- ✅ Have "prompt libraries" organized by scene type
- ✅ Encourage peer feedback on storyboards
- ✅ Emphasize file organization early
- ✅ Preview Class 3 to build excitement
- ✅ **BONUS TIP:** Direct early finishers to AI Music section!

**AI Music Bonus (Optional):**
- Great for students who finish images early
- Music generation takes 5-10 minutes
- Tools are very beginner-friendly (especially Suno)
- Students arrive at Class 3 with complete asset package!
- Don't force it - only for interested students

---

### Class 3 Tips:

**Time Management:**
- **00:00-00:10** - Asset check & review Class 2 (10 min)
- **00:10-00:55** - Learn & create AI videos (45 min)
- **00:55-01:10** - BREAK (15 min)
- **01:10-01:55** - Learn & create AI voices (45 min)
- **01:55-02:55** - Assemble in Canva (60 min) **← Most critical time!**
- **02:55-03:15** - Showcase time! (20 min)
- **03:15-03:25** - Reflection & celebration (10 min)

**Common Challenges:**
1. **Missing Images from Class 2**
   - Solution: 10-min asset check catches this early
   - Students can use still images instead of videos if needed
   
2. **Video Animation Learning Curve**
   - Solution: Demo first, then let students try
   - Remind them: NOT all scenes need animation!
   
3. **Voice Sync Issues**
   - Solution: Canva handles this well - show them how
   - "Good enough is great!" message
   
4. **Canva Assembly Overwhelm**
   - Solution: Provide step-by-step checklist
   - Consider creating a template they can duplicate
   
5. **Time Pressure Before Showcase**
   - Solution: Set hard deadline 15 min before showcase
   - Celebrate completion over perfection

**Pro Tips:**
- ✅ Do a quick asset check at the very start!
- ✅ Demo each tool to whole class before individual work
- ✅ Have Teaching Assistant help with Canva technical issues
- ✅ Encourage students to help each other
- ✅ Set up showcase BEFORE class starts (test speaker/projector)
- ✅ Make showcase special - everyone gets applause!
- ✅ Record presentations (with permission) for portfolios

## 🛠️ Tool Recommendations

### Primary Tools (Teach These):
1. **Images:** DALL·E via ChatGPT (easiest, most integrated)
2. **Video:** Runway ML (best balance of quality and ease)
3. **Voice:** ElevenLabs (most natural-sounding)
4. **Assembly:** Canva (student-friendly, powerful enough)

### Backup Tools (If Primary Unavailable):
- **Images:** Stable Diffusion on HuggingFace
- **Video:** Pika Labs (requires Discord)
- **Voice:** PlayHT
- **Assembly:** iMovie (Mac) / Windows Video Editor

## 💡 Differentiation Strategies

### For Advanced Students:
- Encourage bonus modules (AutoDraw, Teachable Machine)
- Challenge them to help others
- Add music/sound effects to stories
- Create longer, more complex narratives

### For Struggling Students:
- Provide pre-written prompts to modify
- Allow simpler 3-scene stories
- Pair with stronger students for peer support
- Focus on completion over perfection

### For ESL/ELL Students:
- ChatGPT can help translate story ideas
- Visual storytelling reduces text requirements
- Allow native language in planning stages
- Celebrate multilingual stories!

## 🚨 Troubleshooting Guide

### "The tool isn't working!"
1. Check internet connection
2. Try refreshing the page
3. Switch to backup tool
4. Have student work on script/planning while waiting

### "I lost my files!"
1. Check downloads folder
2. Check recent files in tool
3. Recreate quickly with saved prompts
4. Pair with student who can share similar assets

### "My story idea isn't working!"
1. Use ChatGPT to brainstorm alternatives
2. Look at classmates' work for inspiration
3. Simplify to 3 scenes
4. Offer preset theme options

### "I'm running out of time!"
1. Prioritize: Story over polish
2. Use still images instead of videos
3. Use text instead of voice
4. Focus on one great scene

## ❓ FAQ

**Q: What if students don't finish their storyboards in Class 2?**  
A: That's okay! They can have a simpler 3-scene story, or finish planning in first 10 min of Class 3.

**Q: What if students don't create enough images in Class 2?**  
A: Minimum 3 images (one per scene) is fine! Quality over quantity.

**Q: Can students work in groups?**  
A: Individual projects are core for this workshop, but Bonus Module 9 has team option.

**Q: Why does story planning come first now?**  
A: Students are more motivated to learn tools when they're creating THEIR vision! Project-based learning is more engaging.

**Q: What if a tool is blocked/unavailable?**  
A: Use backup tools listed in this guide. Each category has alternatives.

**Q: How do I handle inappropriate prompts?**  
A: Preview prompts before generation, discuss digital citizenship.

**Q: What about students without devices at home?**  
A: Complete everything in class time - no homework required.
